# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates and patches.

| Version | Supported |
|---|---|
| `0.1.x` | ✅ Yes |
| `< 0.1.0` | ❌ No |

## Reporting a Vulnerability

We take the security of the Benni OS ecosystem seriously. If you discover a security vulnerability in `benni-inference-engine`, please report it responsibly:

1. **Do not** file a public GitHub issue.
2. Email the core security team directly at **security@benni-os.net**.
3. Include:
   - A detailed description of the vulnerability.
   - Proof of Concept (PoC) or reproduction steps.
   - Potential impact on consumer hardware or running models.

### Response Timelines

- **Initial Response:** Within 24 hours.
- **Triage & Assessment:** Within 72 hours.
- **Fix & Disclosure:** Patch coordinated within 14 business days.

Thank you for helping keep the sovereign AI ecosystem secure.
